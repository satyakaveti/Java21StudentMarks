Spring AOP

Aspect-Oriented Programming separates cross-cutting concerns — audit logging, performance monitoring, retry logic — from business code. In this project, three aspects run transparently across service methods without a single line of audit or timing code inside the services themselves.

AOP Concepts
Spring AOP uses JDK dynamic proxies or CGLIB to intercept method calls on Spring beans. No bytecode weaving — only Spring-managed beans can be advised.
1 High Level Overview

Key terms:

TermMeaningExample
AspectA class containing cross-cutting logicAuditAspect, PerformanceAspect
AdviceThe actual code that runs@Around, @Before, @AfterThrowing
PointcutWhich methods to interceptexecution(* com.studentresults.service.*.*(..))
Join pointA specific method call being interceptedstudentService.createStudent(request)
WeavingApplying the aspect to the targetSpring wraps the bean in a proxy at startup
2 Examples
Minimal aspect structureSimple
@Aspect       // marks this class as an aspect
@Component    // makes it a Spring bean so it can be proxied
public class LoggingAspect {

    // Pointcut — matches any public method in any service class
    @Pointcut("execution(public * com.studentresults.service.*.*(..))")
    public void serviceMethods() {}  // empty — just names the pointcut

    // Advice — before every service method, log the call
    @Before("serviceMethods()")
    public void logBefore(JoinPoint joinPoint) {
        System.out.println("Calling: " + joinPoint.getSignature().getName());
    }
}
@Pointcut
Reusable pointcut expressions — serviceMethods() for all services, auditableMethods() for @Auditable-annotated methods.
1 High Level Overview

A @Pointcut is a named, reusable expression that defines which join points to match. Pointcut expressions use AspectJ syntax: execution() matches method signatures, @annotation() matches annotated methods, within() matches classes. Combine with &&, ||, !.

2 Examples
Common pointcut expressionsMedium
@Aspect @Component
public class PointcutLibrary {

    // All public methods in all service classes
    @Pointcut("execution(public * com.studentresults.service.*.*(..))")
    public void allServiceMethods() {}

    // Methods annotated with our custom @Auditable
    @Pointcut("@annotation(com.studentresults.aspect.Auditable)")
    public void auditableMethods() {}

    // All methods in the result service specifically
    @Pointcut("within(com.studentresults.service.ResultService)")
    public void resultServiceMethods() {}

    // Service methods that are also auditable
    @Pointcut("allServiceMethods() && auditableMethods()")
    public void auditableServiceMethods() {}

    // All controllers
    @Pointcut("within(@org.springframework.web.bind.annotation.RestController *)")
    public void controllerMethods() {}
}
@Around
AuditAspect wraps all @Auditable methods — measures duration, saves to audit_log before and after, handles exceptions. Most powerful advice type.
1 High Level Overview

@Around completely wraps the target method. You get a ProceedingJoinPoint and call pjp.proceed() to invoke the real method. You can run code before and after, modify arguments, change the return value, or suppress exceptions. Most powerful but also most complex — use @Before/@After for simpler cases.

3 In This Project
aspect/AuditAspect.java
@Aspect
@Component
public class AuditAspect {

    private static final Logger log = LoggerFactory.getLogger(AuditAspect.class);
    private final AuditLogRepository auditLogRepository;

    public AuditAspect(AuditLogRepository auditLogRepository) {
        this.auditLogRepository = auditLogRepository;
    }

    @Around("@annotation(auditable)")   // binds the annotation instance
    public Object auditMethod(ProceedingJoinPoint pjp, Auditable auditable)
            throws Throwable {

        var methodName = pjp.getSignature().getName();
        var args       = Arrays.toString(pjp.getArgs());
        var start      = Instant.now();

        try {
            Object result = pjp.proceed();   // call the real method

            var elapsed = Duration.between(start, Instant.now()).toMillis();

            // Save audit entry
            auditLogRepository.save(AuditLog.builder()
                .action(auditable.action())
                .method(methodName)
                .arguments(args)
                .durationMs(elapsed)
                .outcome("SUCCESS")
                .performedBy(SecurityContextHolder.getContext()
                    .getAuthentication().getName())
                .build());

            return result;  // return the original result to the caller

        } catch (Exception ex) {
            auditLogRepository.save(AuditLog.builder()
                .action(auditable.action())
                .method(methodName)
                .outcome("FAILURE")
                .errorMessage(ex.getMessage())
                .build());
            throw ex;   // re-throw — don't swallow exceptions
        }
    }
}
@Before
Logs method entry with argument values before any service method executes — useful for debugging and request tracing.
1 High Level Overview

@Before runs before the target method. You get a JoinPoint (not ProceedingJoinPoint) — you can read method info and arguments but cannot prevent execution or modify them. Simpler than @Around for pure pre-execution logging.

3 In This Project
aspect/AuditAspect.java — @Before
@Before("execution(* com.studentresults.service.*.*(..))")
public void logMethodEntry(JoinPoint joinPoint) {
    var signature = joinPoint.getSignature();
    var args = joinPoint.getArgs();

    log.debug("→ {}.{}({})",
        signature.getDeclaringType().getSimpleName(),  // e.g. "StudentService"
        signature.getName(),                            // e.g. "createStudent"
        Arrays.stream(args)
            .map(Object::toString)
            .collect(Collectors.joining(", ")));
}
@AfterReturning
Logs successful mark creation with the returned MarkDTO — fires only when the method returns normally (no exception).
1 High Level Overview

@AfterReturning runs after successful method completion. You can access the return value with returning parameter binding. Does not run if an exception is thrown — use @After for always-run cleanup.

3 In This Project
aspect/AuditAspect.java — @AfterReturning
@AfterReturning(
    pointcut = "execution(* com.studentresults.service.ResultService.createMark(..))",
    returning = "result")   // binds the return value to 'result'
public void logMarkCreated(JoinPoint joinPoint, Object result) {
    if (result instanceof MarkDTO markDTO) {    // Java 16 pattern matching instanceof
        log.info("✓ Mark created: studentId={}, subject={}, score={}",
            markDTO.studentId(), markDTO.subjectName(), markDTO.score());
    }
}
@AfterThrowing
Catches any exception from any service method, logs it, and triggers an alert. Does not suppress the exception — it still propagates to the caller.
1 High Level Overview

@AfterThrowing runs when the target method throws an exception. You can bind the exception with throwing. This does not handle or suppress the exception — it still propagates. Use it for centralised logging or alerting without wrapping every service in try/catch.

3 In This Project
aspect/AuditAspect.java — @AfterThrowing
@AfterThrowing(
    pointcut = "execution(* com.studentresults.service.*.*(..))",
    throwing = "ex")   // binds the thrown exception to 'ex'
public void logServiceException(JoinPoint joinPoint, Exception ex) {
    log.error("✗ Exception in {}.{}: {}",
        joinPoint.getSignature().getDeclaringType().getSimpleName(),
        joinPoint.getSignature().getName(),
        ex.getMessage());

    // Alert on unexpected exceptions (not business exceptions like NotFound)
    if (!(ex instanceof BusinessException)) {
        alertService.sendAlert("Unexpected service error: " + ex.getMessage());
    }
    // Exception still propagates — we're just observing, not handling
}
@After
Always-runs cleanup logging — fires whether the method succeeded or threw an exception. Used for resource/connection cleanup logging.
1 High Level Overview

@After is the finally-equivalent in AOP — always runs regardless of outcome. Use it for guaranteed cleanup: closing resources, clearing thread-local state, or always-on metrics. Runs after @AfterReturning or @AfterThrowing.

3 In This Project
aspect/AuditAspect.java — @After
@After("@annotation(com.studentresults.aspect.Auditable)")
public void logMethodExit(JoinPoint joinPoint) {
    // Runs after the method — success or failure
    log.debug("← {}.{} completed",
        joinPoint.getSignature().getDeclaringType().getSimpleName(),
        joinPoint.getSignature().getName());
}
Custom @Auditable Annotation
@Auditable marks which service methods should be audited. The AuditAspect intercepts them by matching @annotation(Auditable) — clean separation of concern.
1 High Level Overview

Define a custom annotation and use it as a pointcut with @annotation(). This is cleaner than execution-based pointcuts for selective auditing — you opt methods into auditing explicitly by annotating them, rather than matching by name pattern.

3 In This Project
aspect/Auditable.java · service/StudentService.java
// 1. Define the annotation
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Auditable {
    String action() default "";   // optional label for the audit log
}

// 2. Apply to service methods you want audited
@Service
public class StudentService {

    @Auditable(action = "CREATE_STUDENT")
    public StudentDTO createStudent(CreateStudentRequest request) { ... }

    @Auditable(action = "DELETE_STUDENT")
    public void softDeleteStudent(Long id) { ... }

    // Not annotated — not audited
    public StudentDTO getStudentById(Long id) { ... }
}

// 3. Aspect intercepts based on the annotation
@Around("@annotation(auditable)")
public Object audit(ProceedingJoinPoint pjp, Auditable auditable) throws Throwable {
    // auditable.action() = "CREATE_STUDENT"
}
Performance Aspect
Wraps all service methods — logs a WARNING if any service call takes more than 500ms. Zero changes to service code needed.
3 In This Project
aspect/PerformanceAspect.java
@Aspect
@Component
public class PerformanceAspect {

    private static final Logger log = LoggerFactory.getLogger(PerformanceAspect.class);
    private static final long SLOW_THRESHOLD_MS = 500;

    @Around("execution(* com.studentresults.service.*.*(..))")
    public Object measureTime(ProceedingJoinPoint pjp) throws Throwable {
        var start  = Instant.now();
        var result = pjp.proceed();
        var elapsed = Duration.between(start, Instant.now()).toMillis();

        if (elapsed > SLOW_THRESHOLD_MS) {
            log.warn("🐢 SLOW: {}.{}() took {}ms (threshold: {}ms)",
                pjp.getSignature().getDeclaringType().getSimpleName(),
                pjp.getSignature().getName(),
                elapsed, SLOW_THRESHOLD_MS);
        } else {
            log.debug("⚡ {}.{}() = {}ms",
                pjp.getSignature().getDeclaringType().getSimpleName(),
                pjp.getSignature().getName(), elapsed);
        }
        return result;
    }
}
Retry Aspect
Retries service methods up to 3 times on transient DB errors (deadlocks, connection timeouts) with exponential backoff — without any retry logic inside the service itself.
3 In This Project
aspect/RetryAspect.java
@Aspect
@Component
public class RetryAspect {

    private static final Logger log = LoggerFactory.getLogger(RetryAspect.class);
    private static final int MAX_RETRIES = 3;

    @Around("@annotation(com.studentresults.aspect.Retryable)")
    public Object retry(ProceedingJoinPoint pjp) throws Throwable {
        int attempts = 0;
        while (true) {
            try {
                return pjp.proceed();
            } catch (TransientDataAccessException | CannotAcquireLockException ex) {
                attempts++;
                if (attempts >= MAX_RETRIES) {
                    log.error("Failed after {} retries: {}", MAX_RETRIES, ex.getMessage());
                    throw ex;
                }
                long backoff = (long) Math.pow(2, attempts) * 100; // 200ms, 400ms
                log.warn("Transient error, retry {}/{} in {}ms: {}",
                    attempts, MAX_RETRIES, backoff, ex.getMessage());
                Thread.sleep(backoff);
            }
        }
    }
}

// Custom annotation
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Retryable { }

// Usage in service
@Retryable
public MarkDTO createMark(Long studentId, CreateMarkRequest request) { ... }
