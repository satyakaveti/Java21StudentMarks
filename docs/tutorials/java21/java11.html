HTTP Client API JEP 321
Used in this project — calls external grade import API with HTTP/2, timeout, and async support.
1 High Level Overview

The new java.net.http.HttpClient replaces HttpURLConnection. It supports HTTP/1.1 and HTTP/2, WebSockets, async requests via CompletableFuture, request/response body handlers, timeout configuration, redirect policies, and cookie management. The client is immutable and thread-safe. Built with a fluent builder API.

2 Examples
Simple GET requestSimple
HttpClient client = HttpClient.newHttpClient();

HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/students"))
    .GET()
    .build();

HttpResponse<String> response =
    client.send(request, HttpResponse.BodyHandlers.ofString());

System.out.println(response.statusCode()); // 200
System.out.println(response.body());       // JSON string
HTTP/2 async with timeoutMedium
HttpClient client = HttpClient.newBuilder()
    .version(HttpClient.Version.HTTP_2)
    .connectTimeout(Duration.ofSeconds(10))
    .followRedirects(HttpClient.Redirect.NORMAL)
    .build();

HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://grades-api.example.com/import"))
    .header("Authorization", "Bearer " + apiKey)
    .header("Accept", "application/json")
    .timeout(Duration.ofSeconds(30))
    .GET()
    .build();

// Async — non-blocking
client.sendAsync(request, HttpResponse.BodyHandlers.ofString())
    .thenApply(HttpResponse::body)
    .thenAccept(body -> processGrades(body))
    .exceptionally(ex -> { log.error("Import failed", ex); return null; });
POST JSON bodyReal-time
String json = """
    {"studentId": 42, "subject": "MATHS", "score": 87}
    """;

HttpRequest post = HttpRequest.newBuilder()
    .uri(URI.create("https://marks-api.example.com/submit"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(json))
    .build();

HttpResponse<String> resp =
    client.send(post, HttpResponse.BodyHandlers.ofString());
if (resp.statusCode() != 201) throw new RuntimeException("Submit failed");

String API Enhancements
Used in this project — isBlank() for input validation, strip() for trimming, lines() for CSV parsing, repeat() for test data.
1 High Level Overview

Java 11 added several long-overdue String utilities: isBlank() returns true for empty or whitespace-only strings (Unicode-aware). strip() / stripLeading() / stripTrailing() are Unicode-aware trim (unlike trim() which only handles ASCII whitespace). lines() returns a Stream<String> of lines. repeat(n) repeats a string n times.

2 Examples
isBlank, strip, repeatSimple
"  ".isBlank();           // true  (spaces only)
"  hello  ".strip();      // "hello"  (Unicode-aware)
"  hello  ".trim();       // "hello"  (ASCII only — older)
"  hello  ".stripLeading(); // "hello  "
"ha".repeat(3);           // "hahaha"
"".isBlank();             // true
Parse CSV with lines()Medium
String csv = """
    name,roll,score
    Alice,STU001,87
    Bob,STU002,65
    
    Charlie,STU003,92
    """;

List<Student> students = csv.lines()
    .skip(1)                         // skip header
    .filter(line -> !line.isBlank()) // skip blank lines
    .map(line -> line.split(","))
    .map(parts -> new Student(parts[0].strip(),
                               parts[1].strip(),
                               Integer.parseInt(parts[2].strip())))
    .collect(Collectors.toList());

var in Lambda Parameters
Used in this project — allows @NotNull annotation on lambda params.
1 High Level Overview

Java 11 extended var to lambda parameters, enabling annotations on them — something not possible with inferred types or explicit types before. The primary use case is adding @NotNull, @NonNull, or custom annotations to lambda parameters for static analysis tools.

2 Examples
Annotated lambda paramsSimple
// var in lambda — enables annotations
list.stream()
    .filter((@NonNull var s) -> !s.isBlank())
    .map((@NonNull var s) -> s.toUpperCase())
    .forEach(System.out::println);

// Note: all params must use var if any use it
// This is invalid: (var a, String b) -> a + b
Single File Source Execution
Not in main source. Used for quick dev utility scripts.
1 High Level Overview

Java 11 allows running a single .java file directly with java FileName.java — no explicit javac compilation step needed. The file is compiled in memory and run. Useful for scripts, quick prototypes, and learning. The file can contain multiple classes but only one public class.

2 Examples
Run without compilingSimple
// SeedData.java
public class SeedData {
    public static void main(String[] args) throws Exception {
        var url = "jdbc:postgresql://localhost:5432/students_db";
        try (var conn = java.sql.DriverManager.getConnection(url, "postgres", "postgres");
             var stmt = conn.createStatement()) {
            stmt.execute("INSERT INTO subjects(name) VALUES ('MATHS'),('SCIENCE'),('ENGLISH')");
            System.out.println("Subjects seeded.");
        }
    }
}
// Run: java SeedData.java  (no javac needed)
TLS 1.3
Not in application source code. Automatically used when connecting via HTTPS. Spring Boot's SSL bundle configuration handles certificate management.
1 High Level Overview

Java 11 added full TLS 1.3 support (JEP 332). TLS 1.3 is faster (1-RTT handshake vs 2-RTT in 1.2), more secure (removed weak cipher suites), and has a 0-RTT resumption option. It is automatically used by HttpClient, Spring's RestClient, and all HTTPS connections when the server supports it.

2 Examples
Force TLS 1.3Simple
// HttpClient — specify TLS version
SSLContext sslContext = SSLContext.getInstance("TLSv1.3");
sslContext.init(null, null, null);

HttpClient client = HttpClient.newBuilder()
    .sslContext(sslContext)
    .build();

// Spring Boot application.yml
server:
  ssl:
    enabled: true
    bundle: myssl
    enabled-protocols: TLSv1.3
Java Flight Recorder (JFR)
Not in application source code. Used as an ops/profiling tool to diagnose production performance issues.
1 High Level Overview

Java Flight Recorder (JEP 328) is a low-overhead profiling and diagnostics tool built into the JVM. It records JVM events (GC, threads, I/O, exceptions, method profiling) with less than 1% overhead. Previously commercial in Oracle JDK, it became free/open in Java 11. Analysed with JDK Mission Control (JMC).

2 Examples
Start JFR recordingSimple
// Start recording at app launch
java -XX:StartFlightRecording=duration=60s,filename=student-portal.jfr \
     -jar student.jar

// Or programmatically
Recording recording = new Recording();
recording.enable("jdk.GarbageCollection");
recording.enable("jdk.VirtualThreadStart");
recording.start();
// ... do work ...
recording.stop();
recording.dump(Path.of("recording.jfr"));
