Records JEP 359 — Preview → Standard in Java 16
Used in this project — all DTOs and request/response objects: StudentDTO, MarkDTO, CreateMarkRequest, AuthResponse, AppProperties.
1 High Level Overview

Records are immutable data carriers. A single record declaration auto-generates: constructor, accessors (named after components, not getXxx), equals(), hashCode(), and toString(). Fields are implicitly private final. Records cannot extend classes but can implement interfaces. A compact constructor allows validation before field assignment.

2 Examples
Basic record — replaces DTO classSimple
// 40+ lines of boilerplate → 1 line
public record StudentDTO(Long id, String name, String rollNumber, String email) {}

// Usage — accessors named after components (not getXxx)
var dto = new StudentDTO(1L, "Alice", "STU001", "alice@example.com");
dto.name();        // "Alice"
dto.rollNumber();  // "STU001"
dto.id();          // 1L

// equals/hashCode/toString auto-generated
System.out.println(dto);
// StudentDTO[id=1, name=Alice, rollNumber=STU001, email=alice@example.com]
Record with compact constructor validationMedium
public record CreateMarkRequest(
    @NotNull Long subjectId,
    @Min(0) @Max(100) int score,
    @NotNull LocalDate examDate
) {
    // Compact constructor — runs before fields assigned
    public CreateMarkRequest {
        if (score < 0 || score > 100)
            throw new IllegalArgumentException("Score must be 0–100");
        if (examDate.isAfter(LocalDate.now()))
            throw new IllegalArgumentException("Exam date cannot be future");
        // Fields assigned automatically after this block
    }
}

Pattern Matching for instanceof JEP 305 — Preview → Standard in Java 16
Used in this project — event type checking in NotificationService.
1 High Level Overview

Before Java 14, every instanceof check needed a separate cast. Pattern matching combines the type test and cast in one: if (obj instanceof String s) — if true, s is in scope as a String. The bound variable s is only in scope where the pattern is known to match. Negation works: if (!(obj instanceof String s)) return; — s is available after the return.

2 Examples
Eliminate redundant castSimple
// Before — check + cast (redundant)
if (obj instanceof String) {
    String s = (String) obj;    // redundant cast
    System.out.println(s.length());
}

// After — check + bind
if (obj instanceof String s) {
    System.out.println(s.length());  // s is String here
}

// Works with negation too
if (!(obj instanceof String s)) return;
System.out.println(s.length());  // s in scope after guard

Helpful NullPointerExceptions JEP 358
Enabled by default — improves debugging throughout the project without any code changes.
1 High Level Overview

Before Java 14, NPEs said only the line number: "NullPointerException at line 42". With helpful NPEs, the JVM message now says exactly which variable was null and which operation failed: "Cannot invoke 'Student.getName()' because 'student' is null". Enabled by default in Java 14+. Dramatically reduces debug time for chained calls.

2 Examples
Before vs afterSimple
// Code
String city = student.getAddress().getCity().toUpperCase();

// Java 13 NPE — useless
// NullPointerException

// Java 14+ NPE — precise
// Cannot invoke "Address.getCity()" because the return value of
// "Student.getAddress()" is null

// Another example
marks[0].getSubject().getName();
// Cannot read the array element at index 0 because "marks" is null
Switch Expressions — Standard JEP 361
Used in this project — switch expressions are now standard, no --enable-preview flag needed.
1 High Level Overview

Switch expressions graduated from preview (Java 12–13) to standard in Java 14. The arrow syntax, yield, multiple labels per arm, and exhaustiveness checks are all stable. No more --enable-preview flag required. This paved the way for pattern matching in switch (Java 21).

3 In This Project
service/impl/ResultServiceImpl.java — standard, no preview flag
// Standard since Java 14 — no --enable-preview needed
private String calculateGrade(int score) {
    return switch (score) {
        case int s when s >= 75 -> "A";
        case int s when s >= 50 -> "B";
        case int s when s >= 35 -> "C";
        default                 -> "F";
    };
}

private String passFailStatus(String grade) {
    return switch (grade) {
        case "A", "B", "C" -> "PASS";
        case "F"            -> "FAIL";
        default -> throw new IllegalArgumentException("Unknown: " + grade);
    };
}
