Records — Standard JEP 395
Used in this project — all DTOs finalized as records, no preview flag needed.
1 High Level Overview

Records graduated from preview (Java 14–15) to standard in Java 16. They are now a permanent, stable language feature. The @RecordComponent annotation type is also available for framework use. Spring Boot 2.7+ has full record support; Spring Boot 3.x uses records for @ConfigurationProperties.

Pattern Matching for instanceof — Standard JEP 394
Used in this project — event handling in NotificationService, no preview flag needed.
1 High Level Overview

Pattern matching for instanceof graduated from preview (Java 14–15) to standard in Java 16. Binding variables from instanceof patterns are now a permanent language feature. This laid the foundation for the far more powerful pattern matching in switch expressions (Java 21).

Vector API JEP 338 — Incubator
Not used in this project. Vector API targets numerical/scientific computing — SIMD operations on arrays. Still incubating as of Java 21.
1 High Level Overview

The Vector API expresses vector computations that compile to optimal SIMD (Single Instruction Multiple Data) hardware instructions. It allows processing multiple data elements in parallel using CPU vector registers. Useful for image processing, ML inference, signal processing, and numerical algorithms. Not useful for typical web application code.

2 Examples
Vectorized array sumSimple
// Scalar — processes one element at a time
int scalarSum(int[] array) {
    int sum = 0;
    for (int x : array) sum += x;
    return sum;
}

// Vector — processes 8 ints at once (AVX2)
static final VectorSpecies<Integer> SPECIES = IntVector.SPECIES_256;

int vectorSum(int[] array) {
    var sum = IntVector.zero(SPECIES);
    int i = 0;
    for (; i < SPECIES.loopBound(array.length); i += SPECIES.length()) {
        var v = IntVector.fromArray(SPECIES, array, i);
        sum = sum.add(v);
    }
    int result = sum.reduceLanes(VectorOperators.ADD);
    for (; i < array.length; i++) result += array[i]; // tail
    return result;
}
Unix-Domain Socket Channels JEP 380
Not used in this project. Useful for high-performance local IPC between processes on the same machine.
1 High Level Overview

Unix-domain sockets enable faster inter-process communication (IPC) on the same machine — no TCP/IP stack overhead. Java 16 added UnixDomainSocketAddress and support in ServerSocketChannel / SocketChannel. Useful for communication between a Java app and a local service (sidecar, agent, database proxy) without network overhead.

2 Examples
Unix socket server/clientSimple
Path socketFile = Path.of("/tmp/student-portal.sock");

// Server
ServerSocketChannel server = ServerSocketChannel.open(StandardProtocolFamily.UNIX);
server.bind(UnixDomainSocketAddress.of(socketFile));
SocketChannel client = server.accept();

// Client (another process on same machine)
SocketChannel socket = SocketChannel.open(StandardProtocolFamily.UNIX);
socket.connect(UnixDomainSocketAddress.of(socketFile));
socket.write(ByteBuffer.wrap("ping".getBytes()));
